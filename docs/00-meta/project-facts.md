# 프로젝트 기본 정보 (발표자료 수치의 유일한 근거, 임의 변경 금지)

## 개발 기간 및 투입 공수
- 개발 기간: 2026년 7월 1일 ~ 2026년 10월 6일 (98일, 14주, 약 3개월)
- 투입 시간: 주 3시간 (업무 외 병행)
- 총 투입 시간: 42시간 (14주 × 3시간)
- 환산: 약 5.3MD (8시간/일 기준), 약 0.26MM (160시간/월 기준)
- 비고: 발표 시 "산정 기준 주 3시간"으로 명시
- 기간 구분: 2026년 7월 = 기획 및 SPEC 작성 기간(코드 커밋 없음), 2026년 8월 2일 첫 커밋(Phase 0) 이후 = 구현 기간. 발표 시 7월은 "기획, SPEC 작성"으로 표기

## AI 도구
- 사용 도구: Claude Code CLI 단독 사용 (다른 AI 도구 미사용)
- 사용 모델: Claude Opus 4.8 ~ Claude Opus 5.5 (개발 기간 중 모델 버전 업데이트에 따라 순차 사용)
- 구독 플랜 및 월 비용: Claude Pro 플랜, 월 20달러
- 구독 기간: 4개월 (2026년 7월 ~ 10월)
- 기간 총 비용: 80달러 (20달러 × 4개월)

## 비교 기준 (선택)
- 기존 방식 예상 공수: 약 135MD (약 1,080시간, 약 6.8MM) — **Claude 추정**, 발표 시 반드시 "추정"과 산정 근거를 함께 표기
  - 산정 방식: 코드 규모 ÷ 가정 생산성
  - 코드 규모(커밋 7c003a3 기준 실측): 약 27,000줄 = 백엔드 Java 12,229줄 + 테스트 Java 5,326줄 + 프론트엔드 TS/TSX 9,463줄
  - 가정 생산성: 1MD당 200줄(설계·테스트 포함, 문서화·배포 구성은 미포함) — 업계 실측치가 아닌 가정값
  - 참고 규모(실측): REST API 105개, JPA 엔티티 29개, 화면(pages) 22개, Flyway 마이그레이션 18개, docs/ MD 39개 6,584줄
  - 비교: 실제 투입 42시간 대비 약 26배 (1,080 ÷ 42, 추정치 기준)
- 주 40시간 전업 투입 환산(파일럿 비교 기준, **Claude 추정, 단순 선형 환산**)
  - 본 사례 시간당 산출: 약 27,000줄 ÷ 42시간 ≈ 시간당 약 643줄
  - 1인 주 40시간 환산: 643줄 × 40시간 ≈ 주 약 25,700줄
  - 기존 방식 가정: 1MD당 200줄 × 주 5일 = 주 1,000줄
  - 주의: 규모가 커지면 검토, 검증 시간이 늘어 선형으로 유지되지 않을 수 있음 — 발표 시 "추정"과 산정 기준을 함께 표기하고, 2단계 파일럿에서 실측으로 검증
- 월 단위 비교(발표 14페이지 표, 월 = 주 40시간 × 4주 = 160시간 기준)
  - 본 사례(실측, 업무 외 병행): 주 약 3시간, 월 약 10.5시간(42시간 ÷ 구독 4개월), 월 평균 약 6,750줄(27,000줄 ÷ 4개월)
  - 전업 개발자 + AI 활용(추정): 주 40시간, 월 160시간, 본 사례 분량 약 1주(42시간 ÷ 40시간), 월 약 102,900줄(643줄 × 160시간)
  - 전업 개발자 기존 방식(가정): 주 40시간, 월 160시간, 본 사례 분량 약 27주(1,080시간 ÷ 40시간), 월 약 4,000줄(200줄 × 20일)
